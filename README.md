# 陕西师范大学 本科毕业论文（设计）文献综述 · LaTeX 模板

按学校《本科生毕业论文（设计）文献综述》格式要求排版的 LaTeX 模板，中文排版（`ctex`），
**XeLaTeX 编译，开箱即用**。封面、摘要、章节层级、图、表、公式、参考文献的字号与间距已全部按要求设好，
只需替换内容即可。

## 特点

- **格式合规**：标题层级、正文字号、行距、图表题注位置均按学校要求设定，无需自行调整
- **注释完备**：.tex 中每一处该填什么、怎么填都写在旁边，改完即用
- **本机 / Overleaf 双方案**：一个开关切换字体集，两处都能编译出同样效果
- **自带排版示例**：图（含题注位置）、三线表、带编号公式各有一处可直接照抄的范例
- **零警告**：示例文档编译结果为 0 处 `Overfull`、0 处未定义引用

## 快速开始

### Overleaf

1. 新建项目 → **Upload Project**，上传本仓库全部文件（含 `figures/`）
2. 菜单 → **Compiler** 选 **XeLaTeX**
3. 保持文件开头的 `\overleaftrue`，点击编译

### 本地编译（TeX Live / MiKTeX）

```bash
xelatex 文献综述_模板.tex
xelatex 文献综述_模板.tex     # 第二遍用于生成图表编号与交叉引用
```

想用本机已安装的宋体 / 黑体 / 楷体（输出更接近学校 Word 原版），把文件开头的

```latex
\overleaftrue     % 改为 \overleafalse
```

> 注意：`\overleafalse` 使用 `fontset=windows`，仅在装有中文字体的 Windows 上可用，
> 上传到 Overleaf 时必须改回 `\overleaftrue`。

## 排版规格

| 位置 | 字体 | 字号 | 对齐与间距 |
| --- | --- | --- | --- |
| 一级标题（一、二、…） | 黑体 | 三号（16 pt） | 居中，段前 3 行、段后 2 行 |
| 二级标题（（一）（二）） | 黑体 | 小三（15 pt） | 左对齐，段前段后各 1.5 行 |
| 三级标题（1  2  …） | 黑体 | 四号（14 pt） | 左对齐，段前段后各 1 行 |
| 正文 | 宋体 | 小四（12 pt） | 两端对齐，1.5 倍行距，首行缩进 2 字符 |
| 摘要正文 | 宋体 | 小四 | 同上 |
| 关键词标签 | 黑体 | 小四 | 3—5 个，逗号隔开，末尾无标点 |
| 图题 | 宋体 | 五号（10.5 pt） | 居中，位于**图下方** |
| 表题 | 宋体 | 五号 | 居中，位于**表格上方** |
| 参考文献 | 宋体 | 小四 | GB/T 7714 顺序编码制 |

英文与数字统一使用 Times New Roman。

## 常用写法

模板已封装三个命令，直接调用即可：

```latex
% 章节标题（三级层次）
\hone{一、前言}
\htwo{（一）二级标题}
\hthree{1  三级标题}

% 插图：\figimg{文件}{宽度}{题注}  ← 题注自动排在图下方、宋体五号
\figimg{figures/example.png}{10cm}{图 2-1\quad 图题写在这里。}

% 公式：\eqn{内容}{编号}  ← 居中，右侧自动生成编号
\eqn{\hat{H}\psi = E\psi}{2-1}
% 正文引用：如式~\eqref{eq:2-1} 所示
```

三线表直接用 `booktabs`，照抄模板中表 3-1 的写法即可。

## 常见问题

**图表编号显示成 `??`**
交叉引用需要编译两遍，再编译一次即可。

**插入的图片不显示，或报 `File not found`**
把图片放进 `figures/`，并检查 `.tex` 中的路径与文件名是否一致。
文件名建议用英文，中文或全角字符（如 `。`）在部分环境下会引发路径问题。

**表格右侧超出页面**
列宽合计（加上每列两侧各 3 pt 的 `\tabcolsep`）不要超过正文可用宽度 15 cm。
模板中表 3-1 的列宽合计即按此设定，可参考着改。

**参考文献编号顺序不对**
`thebibliography` 的编号按 `\bibitem` 出现的先后自动生成，
所以 `\bibitem` 的排列顺序应与正文**首次引用**它们的先后一致。
本模板采用顺序编码制，正文引用处用 `\cite{key}`，不要手写 `[1]` 这样的编号。

**图题里想注明图来自哪篇文献，怎么写**
用作者—年份式，例如「（据 Zhang 等 (2015) 重绘）」，
**不要**写「据文献 [12]」——该编号会被当作一次正文引用，打乱参考文献的编号顺序。

**占位符 `××××` 出现奇怪的换行**
模板已在导言区用 `\xeCJKDeclareCharClass{CJK}{"00D7}` 把 `×`（U+00D7）声明为中文字符，
否则一长串 `×` 会被 LaTeX 当作不可分割的英文单词而溢出页面。替换成正文后这行可保留。
